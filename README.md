# KuthaKo Web

> A new way to connect.

The web experience for **KuthaKo** — bringing identity, trust, and real-world connections together.

## Overview

KuthaKo makes connecting with people simpler.

**Meet. Trust. Scan. Connected.**

This repository contains the web application powering the KuthaKo web experience.

## Features

- Modern, responsive web experience
- Product-focused landing page
- Modular UI architecture
- Responsive design
- Smooth interactions
- Lazy-loaded content
- QR-based connection experience

- CSS
